# Sahaya: A Responsible AI Teaching Assistant (Mini Project)

An AI-generated animated video (~9 minutes) simulating an AI teaching assistant ("Sahaya") in a classroom. Mini project at Dayananda Sagar University, Bangalore (B.Tech CSE-AI/ML).

**Video:** https://youtu.be/DBe8hEzxHis

The video demonstrates responsible AI behaviour in education: an AI that supports a student's thinking instead of replacing it. All characters are AI-generated and fictional.

## How it was built

1. **Input:** a skill file describing the scenario and behaviours to demonstrate (see [`skill/`](skill/)). We uploaded it to Claude.
2. **Prompt:** a single prompt, `Generate a video` (see [`prompts/prompts-log.md`](prompts/prompts-log.md)).
3. **Generation:** Claude, using the animation-studio plugin, produced the video from the skill file in one run. We made no edits to the output.
4. **Publishing:** the video was uploaded to YouTube and the supporting material to this repository.

## What the video demonstrates

| Scene | Behaviour shown |
|-------|-----------------|
| 1. Disclosure | The AI states it is an AI, what it cannot do, and that it can be wrong |
| 2. Helping well | Clear explanation of AI vs ML; flags uncertainty on a historical date and asks the student to verify it |
| 3. Challenge moment | Student asks the AI to write a graded assignment; the AI refuses and offers an outline and feedback instead |
| 4. Verification routine | Teacher walks through the "Ask, Then Check, Then Judge" method; an AI answer is treated as a claim, not a fact |
| 5. Privacy, control, human handoff | Student can decline suggestions; the AI asks what data it needs; the human teacher stays in the loop |
| Reflection | Summary of design principles and limitations |

## Tech stack

Claude (LLM), animation-studio plugin

## Limitations

- This is a single-prompt generation. Our contribution is supplying the skill file, running the prompt, reviewing the result, and publishing it.
- The video's own reflection lists: limited support for other languages and accessibility needs, limited variety of "visitor" behaviour, and no clear escalation path for students who are stressed rather than just rushed.

## Note on AI use

The video was generated by Claude from a skill file we supplied, using the single prompt above. The scenario and scene structure come from that skill file, not from our own script. We watched the output and found it matched the intended behaviours; no regeneration or editing was needed.
